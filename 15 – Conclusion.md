## Objectif

Conclure l'analyse fonctionnelle du projet en récapitulant les principaux éléments définis dans le cahier des charges.

---

# Bilan du projet

Le projet consiste à concevoir un nouveau site internet pour le restaurant **Le Chemin d'Himalaya** afin de remplacer le site existant, créé en 2006.

L'analyse des besoins a permis d'identifier les fonctionnalités attendues ainsi que les différents profils d'utilisateurs concernés par le projet.

---

# Réponse aux besoins

La solution proposée répond aux besoins identifiés dans le cahier des charges en proposant :

- un espace public permettant de présenter le restaurant et ses services ;
- un espace client accessible après authentification ;
- un espace administrateur permettant la gestion du contenu du site.

Le projet intègre également une architecture Client / Serveur basée sur le modèle MVC ainsi qu'une modélisation des données réalisée selon la méthode Merise.

---

# Documents réalisés

Les travaux réalisés au cours du projet comprennent notamment :

- l'analyse du contexte métier ;
- l'identification de la problématique ;
- la définition des objectifs ;
- l'analyse de l'existant ;
- le benchmark ;
- l'identification des parties prenantes ;
- les personas ;
- le parcours utilisateur ;
- les exigences fonctionnelles et non fonctionnelles ;
- les User Stories ;
- les critères d'acceptation ;
- l'architecture fonctionnelle.

---

# Conclusion

Le cahier des charges a permis de formaliser les besoins du projet et de définir une solution répondant aux attentes exprimées pour le futur site internet du restaurant **Le Chemin d'Himalaya**.

Les différents livrables produits constituent une base de travail pour la conception, le développement et la mise en œuvre de l'application.
