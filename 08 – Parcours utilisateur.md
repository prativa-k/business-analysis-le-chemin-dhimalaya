# 08 – Parcours utilisateur

## Objectif

Décrire le parcours des différents utilisateurs au sein du site internet du restaurant **Le Chemin d'Himalaya** afin de comprendre les principales interactions prévues dans le cahier des charges.

---

## Vue d'ensemble

Le site distingue deux parcours principaux :

- le parcours des visiteurs (espace public) ;
- le parcours de l'administrateur (espace sécurisé).

Cette organisation est représentée dans l'arborescence réalisée avec **GlooMaps**, qui sépare les contenus publics des fonctionnalités administratives.

---

# Parcours du visiteur

## 1. Accéder au site

Le visiteur arrive sur le site internet du restaurant.

Il peut consulter librement les pages publiques.

---

## 2. Consulter les informations

Le visiteur peut :

- consulter la page d'accueil ;
- consulter la carte du restaurant ;
- consulter la galerie.

---

## 3. Utiliser les fonctionnalités publiques

Depuis le site, le visiteur peut :

- consulter le menu ;
- réserver une table ;
- contacter le restaurant.

---

## 4. Accéder à l'espace client

S'il souhaite utiliser les fonctionnalités réservées aux utilisateurs authentifiés, le visiteur peut :

- créer un compte ;
- se connecter.

---

## 5. Déposer un avis

Une fois connecté à son espace client, l'utilisateur peut laisser un avis ou un commentaire concernant son expérience.

---

# Parcours de l'administrateur

## 1. Connexion

L'administrateur accède à un espace sécurisé grâce à son adresse e-mail et son mot de passe.

---

## 2. Gestion du contenu

Depuis le tableau de bord, l'administrateur peut :

- ajouter des plats ;
- modifier des plats ;
- supprimer des plats ;
- gérer les tarifs ;
- créer un compte administrateur.

---

## Synthèse

Le parcours utilisateur repose sur une séparation entre :

- les fonctionnalités accessibles à tous les visiteurs ;
- les fonctionnalités nécessitant un compte client ;
- les fonctionnalités réservées à l'administration du site.
