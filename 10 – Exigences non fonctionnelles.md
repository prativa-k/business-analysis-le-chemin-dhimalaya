# 10 – Exigences non fonctionnelles

## Objectif

Définir les exigences techniques et les contraintes que devra respecter le site internet du restaurant **Le Chemin d'Himalaya**.

---

# Compatibilité

| ID | Exigence |
|----|----------|
| NFR-01 | Le site doit être compatible avec les ordinateurs, les tablettes et les smartphones. |
| NFR-02 | L'interface doit s'adapter automatiquement aux différentes tailles d'écran. |

---

# Sécurité

| ID | Exigence |
|----|----------|
| NFR-03 | L'espace administrateur doit être accessible uniquement après une connexion sécurisée avec une adresse e-mail et un mot de passe. |
| NFR-04 | Le tableau de bord administrateur doit être séparé des pages publiques. |

---

# Architecture technique

| ID | Exigence |
|----|----------|
| NFR-05 | L'application doit reposer sur une architecture Client / Serveur. |
| NFR-06 | L'application doit utiliser le modèle MVC (Modèle – Vue – Contrôleur). |
| NFR-07 | Les responsabilités doivent être réparties entre le navigateur, le routeur, le contrôleur, le modèle et la vue. |

---

# Environnement de développement

| ID | Exigence |
|----|----------|
| NFR-08 | Le développement est réalisé avec Visual Studio Code. |
| NFR-09 | Le projet utilise Docker afin de garantir un environnement d'exécution identique. |
| NFR-10 | Le projet utilise un DevContainer pour préparer automatiquement l'environnement de développement. |
| NFR-11 | Le projet doit pouvoir être exécuté sur les serveurs locaux définis dans le cahier des charges. |

---

# Synthèse

Les exigences non fonctionnelles garantissent que le projet respecte les contraintes techniques définies dans le cahier des charges concernant la compatibilité, la sécurité, l'architecture et l'environnement de développement.
